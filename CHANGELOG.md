# Changelog

All notable changes to GRHS are recorded here.

## 0.4.0 — 2026-10-31

Public review draft.

- Preserves the v0.3 alphabet and modifier-letter aspiration system.
- Defines GRHS explicitly as a Latin-script orthography rather than a separately encoded script.
- Adds normative terminology, conformance classes, longest-match parsing, stable grapheme IDs, and a machine-readable repertoire.
- Corrects the description of `ṃ`: it is a spacing Latin letter used as an orthographic marker, not a combining mark.
- Adds Unicode normalization, input, search, collation, confusable-character, accessibility, versioning, governance, and licensing provisions.
- Adds a prior-art section and a candid list of unresolved linguistic and usability questions.
- Retains speaker, reader, accessibility, and community validation as pending.

## 0.3 — 2026-07-24

Stabilization draft.

- Replaced the earlier collection of unrelated aspirate letters with the consistent U+02B0 modifier-letter aspiration marker.
- Replaced dotless `ı` with ordinary `i`.
- Declared Unicode NFC as the canonical normalization form.
- Added a mechanically checked IPA-to-GRHS sample and validation-status table.

## Earlier working material

Earlier committee-style material explored dotless `ı` and several dedicated modified letters for aspirates. Those forms are historical proposals and are not normative GRHS 0.3 or 0.4 spelling.
